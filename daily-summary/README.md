# daily-summary
 
Your end-of-day update, written for you.
 
- **Start it:** say "run my daily summary", then step away for a few minutes.
- **You get:** a draft summary, with a few questions at the top.
- **You do:** answer the questions until you're happy with the summary and say "good". About 3 minutes.
- **Good to know:** nothing is posted until you say "good". Private notes never go into tickets.
